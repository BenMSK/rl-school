Sample 16 answers per maths question, grade each with an answer key, push probability toward the above-average answers and away from the below-average ones, and the model teaches itself to write long chains of thought, check its work and say "wait" without ever being shown an example. <a class="src" href="https://arxiv.org/html/2501.12948v1">DeepSeek-AI 2025</a>
@@ 6
A class of 16 students all answer the same maths problem. There is no teacher grading style, only the answer key at the back of the book: right or wrong. Each student is compared with the class average. Beat the class, do more of that; fall below, do less. After thousands of problems the students start writing out their steps and double-checking, because that is what kept winning.
@@ 7
OpenAI's o1 (September 2024) showed that a model trained "with large-scale reinforcement learning to reason using chain of thought" jumped on maths and code, but published no recipe. <a class="src" href="https://arxiv.org/abs/2412.16720">OpenAI 2024</a> The open question was whether reasoning needs human-written reasoning traces for SFT, process reward models that grade each step, or search at inference time. <a class="src" href="https://arxiv.org/abs/2501.12948">DeepSeek-AI 2025</a> RLHF-style PPO (<a href="#p-instructgpt">the InstructGPT review</a>) also kept a value model the size of the policy, which for a 671B-parameter base is a serious cost.
@@ 8
Two moves. First, <strong>verifiable rewards</strong>: for maths and code, a program can check the final answer, so no learned reward model is needed and there is nothing to game except the checker. Second, <strong>GRPO</strong> (Group Relative Policy Optimization, from DeepSeekMath, February 2024): replace PPO's value model with the mean and standard deviation of rewards inside a group of samples for the same question. <a class="src" href="https://arxiv.org/abs/2402.03300">Shao 2024</a> Apply both to the base model directly, with no SFT, and see what emerges. That model is <strong>DeepSeek-R1-Zero</strong>. <a class="src" href="https://arxiv.org/abs/2501.12948">DeepSeek-AI 2025</a>

The clipped ratio is PPO's (<a href="#p-ppo">the PPO review</a>). The new part is A<sub>i</sub>: the <strong>group-relative advantage</strong> needs no critic. R1-Zero used β = 0.001; in practice the ratio is applied per token and averaged with a 1/|o<sub>i</sub>| per response. <a class="src" href="https://arxiv.org/html/2501.12948v1">DeepSeek-AI 2025</a> Worked example, rewards [2, 1, 1, 0]: mean 1.0, population std 0.7071, advantages [+1.414, 0, 0, −1.414]; the two middle answers get no gradient.

<strong>From R1-Zero to R1.</strong> R1-Zero's traces were hard to read and mixed languages, so the released model adds four stages: a cold-start SFT on thousands of human-polished long reasoning examples; reasoning RL with an extra language-consistency reward; rejection sampling and SFT on about 800k samples (about 600k reasoning, 200k not); and a final RL stage for helpfulness and harmlessness using reward models. <a class="src" href="https://arxiv.org/html/2501.12948v1">DeepSeek-AI 2025</a>

R1 (January 2025) was the first open recipe and open weights for an o1-class reasoner, and GRPO with verifiable rewards became the default for the 2025 "RLVR" wave: DAPO (March 2025, <a href="#p-dapo">review</a>), Dr. GRPO, GSPO and ScaleRL (October 2025, <a href="#p-scalerl">review</a>) are all edits to the objective above. <a class="src" href="https://arxiv.org/abs/2503.14476">Yu 2025</a> <a class="src" href="https://arxiv.org/abs/2510.13786">Khatri 2025</a> Its distillation result set the pattern for small models: RL makes the teacher, SFT makes the students.
@@ 23
The authors list weak tool use and structured output, overthinking on simple questions, language mixing outside Chinese and English, sensitivity to few-shot prompts, limited software-engineering gains, and the difficulty of building reliable rewards for tasks such as writing. In the discussion they report that process reward models and MCTS both failed at scale: steps are hard to define and label, PRMs get hacked, and the token search space explodes. <a class="src" href="https://arxiv.org/html/2501.12948">DeepSeek-AI 2025</a> Two months later, <strong>Dr. GRPO</strong> ("GRPO Done Right") argued the objective itself is biased: the 1/|o<sub>i</sub>| length normalisation gives long wrong answers a smaller per-token penalty, so responses drift longer; and dividing by the group std over-weights questions that are nearly all right or all wrong. Removing both terms reached 43.3% AIME 2024 with a 7B base in about a day on 8 A100s. The same paper found "aha"-style self-reflection already in DeepSeek-V3-Base before any RL. <a class="src" href="https://arxiv.org/abs/2503.20783">Liu 2025</a> Whether RLVR adds ability or only sharpens it is still contested: at k = 1024 samples the base model solved 13.3% of AIME24 problems the RL model never did, and 0.0% the other way. <a class="src" href="https://arxiv.org/abs/2504.13837">Yue 2025</a>
