policy gradient는 국소적인 방향일 뿐입니다. step을 너무 크게 밟으면 policy가 바뀌고, policy가 방문하는 state가 바뀌고, 다음 batch의 데이터는 더 나쁜 policy에서 나옵니다. 이 고리는 한번 무너지면 회복하지 못할 수 있습니다. 나중에 PPO 논문이 이를 측정했습니다. @@ 8
policy가 얼마나 바뀔 수 있는지에 한도를 둡니다. 이때 변화는 파라미터가 아니라 행동(action 분포 사이의 KL divergence)으로 잽니다. Theorem 1은 새 policy의 return에 대한 lower bound를 줍니다. surrogate의 개선분에서 penalty C · D<sub>KL</sub><sup>max</sup>(π, π̃)를 뺀 값이며, C = 4εγ/(1−γ)<sup>2</sup>이고 ε은 advantage 크기의 최댓값입니다. <a class="src" href="https://ar5iv.labs.arxiv.org/html/1502.05477">Schulman 2015</a> 매 step마다 이 bound를 최대화하면 실제 return은 줄어들 수 없습니다. 이론에서 나온 penalty 계수는 step을 매우 작게 만들기 때문에, 실용 알고리즘은 penalty를 <em>평균</em> KL에 대한 hard constraint로 바꾸고 그 반경을 δ로 둡니다. <a class="src" href="https://ar5iv.labs.arxiv.org/html/1502.05477">Schulman 2015</a>

TRPO는 "step을 얼마나 크게?"라는 질문을 튜닝 문제에서 의미가 있는 제약 조건으로 바꾸었고, 파라미터가 수만 개인 신경망 policy에서도 작동했습니다. 직계 후손은 PPO(2017)로, PPO가 내건 목표는 "first-order optimization만 쓰면서 TRPO의 data efficiency와 안정적인 성능을 얻는 것"입니다. <a class="src" href="https://arxiv.org/abs/1707.06347">Schulman 2017</a> 행동 변화를 KL로 제한한다는 아이디어는 기준 모델에서 출발해 policy를 fine-tuning하는 곳마다 다시 등장합니다. InstructGPT의 RLHF는 언어 모델이 출발점 가까이에 머물도록 "token마다 SFT 모델로부터의 per-token KL penalty"를 더합니다. <a class="src" href="https://arxiv.org/abs/2203.02155">Ouyang 2022</a> 이 제약을 무엇이 대체했는지는 <a href="#p-ppo">PPO 논문 리뷰</a>에서 다룹니다.

이론은 state 전체에 걸친 <em>최대</em> KL에 한도를 두지만, 알고리즘은 <em>평균</em>을 제약하며, 저자들도 이 점을 밝힙니다. <a class="src" href="https://ar5iv.labs.arxiv.org/html/1502.05477">Schulman 2015</a> update마다 Fisher-vector product를 쓰는 conjugate gradient 풀이가 필요하고, 이 방법은 "noise가 들어가는 아키텍처(dropout 등)나 parameter sharing(policy와 value function 사이, 또는 auxiliary task와의 공유)이 있는 아키텍처와 호환되지 않는다"고 합니다. <a class="src" href="https://arxiv.org/abs/1707.06347">Schulman 2017</a> Atari에서는 저자들이 "시간 제약 때문에 오차 통계를 얻지 못했다"고 밝힙니다. <a class="src" href="https://ar5iv.labs.arxiv.org/html/1502.05477">Schulman 2015</a> 재현성 문제는 나중에 발목을 잡았습니다. Henderson et al.은 HalfCheetah에서 똑같은 TRPO run 10개를 다섯 개씩 두 그룹으로 나누었는데, random seed만 달랐는데도 두 그룹이 유의하게 달랐습니다(p = 0.0016). <a class="src" href="https://arxiv.org/abs/1709.06560">Henderson 2018</a>
